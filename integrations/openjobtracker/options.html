投递 Excel 备份（可选）

可选的本地 .xlsx 备份，不影响资料填写或工作台使用。导出时会读取该文件， 按「公司名称 + 应聘岗位」定位行：已存在则直接覆盖该行信息，不存在则追加新行，然后原地保存回该文件。

也可「选择已有 Excel 文件」继续使用已有的投递记录表。
文件句柄仅保存在浏览器本地（IndexedDB），数据不经过任何服务器。 需使用 Chrome / Edge 等支持 File System Access API 的浏览器；权限失效时点击「重新授权写入」即可。
